A browser-based memory matching game built with HTML, CSS and JavaScript, where players race against the clock to match pairs of ocean creatures before exceeding the mismatch limit.

# 📖 Overview

Ocean Match is a browser-based memory game developed during the early stages of my Software Engineering Immersive.

Players flip cards to uncover matching pairs of sea creatures while racing against a countdown timer and avoiding too many mismatches. The project demonstrates core JavaScript concepts including DOM manipulation, event handling, game state management and responsive interface design.

---

# 🎮 How to Play

- Flip two tiles to reveal hidden sea creatures.
- Matching pairs remain face up.
- Non-matching pairs flip back over.
- Match every pair before the timer reaches zero.
- Avoid exceeding the mismatch limit.
- Start a new game at any time and choose from multiple difficulty levels.

---

# ✨ Features

- Three difficulty levels
  - Easy (3×3)
  - Medium (5×4)
  - Hard (6×4)
- Countdown timer
- Mismatch tracking
- Match counter
- Responsive layout
- Built with CSS Grid and Flexbox
- Accessible controls and live game status updates
- Confetti celebration on victory
- Restart game without refreshing the page

# 💻 Run Locally

This project is designed to run locally in your browser.

Clone the repository:

```bash
git clone https://github.com/tomrhysjones/ocean-match.git
```

Navigate into the project:

```bash
cd ocean-match
```

Open the application:

```bash
open index.html
```

Alternatively, open the `index.html` file directly in your preferred web browser.
